# OneGlobe Official Website

A responsive single-page website for the OneGlobe international Discord community.

## Preview

Open `index.html` directly or serve the directory with a local static server.

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publishing with GitHub Pages

1. Push this directory to a GitHub repository.
2. In repository Settings, open Pages.
3. Select the branch (usually `main`) and root directory.
4. Save and wait for GitHub Pages to publish the site.
